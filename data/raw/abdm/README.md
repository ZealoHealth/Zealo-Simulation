# data/raw/abdm — ABDM Health Facility Registry export (request R3, optional)

**Why manual:** https://facility.abdm.gov.in/ is a JavaScript application with a dynamic
search and no robots file; automated access is neither clearly permitted nor practical.

**What to collect:** Gadag taluk facilities — facility name, facility type, ownership
(government / private), address, and coordinates if the registry shows them.

**How:** search the registry by state **Karnataka**, district **Gadag**. Export if the
portal allows it; otherwise transcribe into a CSV with the columns above.

Drop the file here unchanged. Mainly helps with the pharmacy undercount and with
confirming the level of government facilities currently marked "level unconfirmed".
